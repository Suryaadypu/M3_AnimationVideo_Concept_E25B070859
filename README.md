# Derivative Animation Project

This four-minute-fifty-six-second, six-scene video explains the derivative as instantaneous rate of change. It uses the example `f(x) = x²` at `x = 1`, where the derivative is `f′(1) = 2`.

## Mathematics

For `f(x) = x²` at `x = 1`, let the second point be `1 + h`, with `h ≠ 0`:

```text
[f(1+h) − f(1)] / h
= [(1+h)² − 1] / h
= (2h + h²) / h
= 2 + h
```

As `h` approaches zero, the secant slope approaches `2`. Thus `f′(1) = 2`; for this function, `f′(x) = 2x`.
